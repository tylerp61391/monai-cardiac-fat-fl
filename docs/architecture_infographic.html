System Architecture Blueprint • Technical Report Repository: monai-cardiac-fat-fl (v0.1.0)

Modernization of Cardiac Epicardial & Pericoronary Adipose Tissue Quantification

Architectural evolution from legacy single-site TensorFlow 1.14 / Python 2.7 pipeline to a high-throughput, MONAI Bundle & NVIDIA FLARE federated learning framework with strict clinical equivalence.

(a) Legacy Pipeline: MGH CardiacFatQuant

Circa 2018–2020. Constrained to single-threaded CPU loops, legacy CUDA 10.0 nodes, frozen Keras/TF 1.14 graphs, and fragile NRRD layouts.

Input Ingestion Fixed scan.nrrd folder trees only. Fails on clinical DICOM series, multi-frame PACS files, or missing coordinate headers.
Segmentation Engine DeepHeartSeg 2-stage (TF 1.14 / Keras 2.2.4). Locked to Python 2.7 environments. Prone to GPU memory allocation faults.
Morphological Transforms Single-threaded CPU SciPy/SimpleITK loops for chamber Voronoi partitioning & vessel distance transforms. High runtime (>120s/patient).
Deployment Model Isolated workstation scripts. Zero multi-site federated aggregation or privacy-preserving cohort analysis capability.
Throughput: ~0.4 patients/min Status: Deprecated

Mode 1: Single-Stage 3D Distillation

Trains a single-stage 3D SegResNet directly against multi-stage teacher pseudo-labels. Uses FedBN to isolate hospital-specific scanner batch norm statistics while sharing convolutional feature representations.

Mode 2: Federated Cohort Analytics

Aggregates global population distributions (mean volume, HU shifts, standard deviations) via privacy-preserving federated summary statistics without transferring any raw CT images across hospital firewalls.
